# Linux & Network Enumeration Toolkit

## 📌 Description
A Bash-based Linux and Network Enumeration Toolkit that gathers system
information, network configuration, open ports, and running services.
The tool logs all output to a timestamped file for reporting purposes.

## 🛠️ Features
- System information enumeration
- Network interface & routing details
- Open listening ports detection
- Running services listing
- Automatic logging to file

## 🚀 Usage
\`\`\`
chmod +x enum.sh
./enum.sh
\`\`\`
